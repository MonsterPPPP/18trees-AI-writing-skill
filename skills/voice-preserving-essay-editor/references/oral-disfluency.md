# 口播重复与口癖

适用于个人口播与随笔模式。目标是去掉转写过程中的机械重复，保留作者真正的判断、犹豫和语气；不要按禁词表或出现次数批量删除。

## 判断顺序

1. 标出重复音节、结巴式重启、无信息填充词和反复出现的立场引导语。
2. 问每一处重复是否带来新信息：强调、时间变化、认识修正、犹豫、反问或节奏。带来新信息就保留其作用。
3. 对确定无信息的口癖做最小删除或合并。若 ASR 词义不清，先根据上下文核对，不靠猜测补出一个“正确”词。
4. 对照原稿检查：第一人称判断是否仍是作者的判断，情绪力度和有辨识度的口语感是否仍在。

## 常见处理

| 原稿现象 | 处理 |
| --- | --- |
| “生、生、生”一类重复音节，且目标词能从上下文确认 | 留一次目标词；确认不了就标明疑点，不编造词义。 |
| “我就，我就愣住了”一类句子重启 | 删除被打断且未增加意义的前半截，保留“我愣住了”等原有语气。 |
| 同一判断里反复说“我觉得……我觉得……” | 通常保留一次必要的主观标记，删掉其余机械引导；不能把个人判断改写成无条件事实。 |
| “我越来越觉得……” | 若“越来越”表达真实的程度或时间变化，就保留；只有明显口癖且不承担变化意义时才简化。 |
| “以前我觉得 A，现在不这么觉得了” | 两次都保留，因为它们呈现认识变化。 |
| 反复追问、刻意排比或迟疑 | 若呈现新的疑问、强调或真实的不确定性，保留其信息，不当作噪声删除。 |

“就是说”“然后”“其实”“这个”等也逐处判断。它们能承担转折、时间顺序或指代时保留；只是口头垫词时删除。删完仍要让文章读起来像作者本人，不追求完全书面化。
